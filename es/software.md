<div class="academic-page">
  <p class="lede">
    Contribuyo al desarrollo y al mantenimiento de software de código abierto para el análisis demográfico y del parentesco.
    Estas herramientas sirven de apoyo a la investigación reproducible y a la docencia en demografía formal y computacional.
  </p>

  <section class="pkg">
    <h2 class="pkg-title">
      <img class="pkg-logo" src="{{ site.baseurl }}/img/logos/rsocsim.png" alt="" width="85" height="96" loading="lazy">
      <span>rsocsim</span>
    </h2>
    <p>
      <a href="https://mpidr.github.io/rsocsim/">rsocsim</a> es una interfaz de R para SOCSIM, una plataforma de código abierto de microsimulación demográfica estocástica.
      Permite ejecutar simulaciones de SOCSIM desde R para generar poblaciones sintéticas con estructuras de parentesco verosímiles
      a partir de tasas demográficas por edad (p. ej., de fecundidad, mortalidad y nupcialidad). Este marco se ha utilizado para estudiar la disponibilidad de familiares,
      el solapamiento generacional y la pérdida de familiares bajo distintos regímenes demográficos.
    </p>
    <p class="pkg-links">
      Documentación: <a href="https://mpidr.github.io/rsocsim/">mpidr.github.io/rsocsim</a><br>
      Código fuente: <a href="https://github.com/MPIDR/rsocsim">github.com/MPIDR/rsocsim</a>
    </p>
  </section>

  <section class="pkg">
    <h2 class="pkg-title">
      <img class="pkg-logo" src="{{ site.baseurl }}/img/logos/demokin.png" alt="" width="83" height="96" loading="lazy">
      <span>DemoKin</span>
    </h2>
    <p>
      <a href="https://ivanwilli.github.io/DemoKin/">DemoKin</a> es un paquete de R para el análisis demográfico matricial de las redes de parentesco.
      Estima el número de familiares y su distribución por edad para numerosos tipos de parientes, y admite modelos de un sexo y de dos sexos,
      incluidas especificaciones variables en el tiempo y multiestado. El paquete está diseñado para modelar el parentesco a nivel poblacional
      con supuestos demográficos explícitos.
    </p>
    <p class="pkg-links">
      Documentación: <a href="https://ivanwilli.github.io/DemoKin/">ivanwilli.github.io/DemoKin</a><br>
      Código fuente: <a href="https://github.com/IvanWilli/DemoKin">github.com/IvanWilli/DemoKin</a>
    </p>
  </section>
